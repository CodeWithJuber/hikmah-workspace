# V6 verification record

The earlier regression suite and newly added suites comprise 177 automated tests. They passed across the full regression run and targeted runs for subsequent lifecycle fixes. TypeScript checking passes. The managed application build succeeds. Bundle-size warnings remain; no browser rendering, accessibility audit, load test or real-key provider request was performed in this update.

Verified with deterministic fixtures and mocked provider streams:

- single-byte SSE framing, provider-returned model attribution, readable explanation streaming, opaque continuation preservation;
- partial answer checkpoint serialization and resume without discarding completed text;
- explicit original task supplied to resumed review; invalid review and truncated repair marked as failed stages while preserving the completed draft;
- legacy provider relay authentication, same-origin checks, CORS-independent relay flow, and sanitized failure handling;
- new checkpoint endpoint owner enforcement, real parameter serialization to a mocked R2/D1 runtime, server-recomputed development gate, refusal of client-forged approval, and stale-activation protection;
- sparse parser tree validity, prototype-name handling, invalid weight/metadata rejection, nontrain exclusion, finite empty-denominator behavior, unresolved reference handling and literal retention.

An independent exhaustive decoder review checked 2,250 random small graphs and enumerated 248,589 valid trees. All feasible optima matched; disconnected cases were rejected. This is algorithm correctness evidence, not linguistic accuracy.

The distributed training-worker bundle was executed through a Node worker adapter on the real English training corpus plus one reviewed correction. It produced 828 training sentences, 17,546 tokens and one retained reviewed row. Development LAS remained 0.534492123845736, so this example does not establish a performance gain or qualify for automatic activation. The worker result is retained in `worker-training-check.json`.

The five released models were evaluated on a document-group PUD partition. Full results, protocol, preprocessing and correctness-revision notes are in the public model reports. The development/test scores are syntactic, using gold segmentation; they do not validate automatic scope resolution, broad meaning or AGI.

The original Quran research package's 191 recorded file hashes were checked, with complete 6,236-row coverage. That validates package integrity and the preserved AI first-pass records. It does not independently certify every interpretation.

Source changes include a new append-only D1 migration for context metadata and an R2 binding for parameter blobs. The existing applied migration is unchanged. Actual production storage availability depends on successful deployment; local runtime adapters do not prove the live cloud path. Provider-specific generation success likewise needs the user's selected model and key.
