# Hikmah workbench

The execution sidecar: an interactive terminal, SSH to hosts the owner has
saved, and shell commands the assistant may run behind an approval gate.

## Why this is a separate service

Next.js has no production path for a WebSocket. A route handler cannot accept an
upgrade, `NextResponse.upgrade()` is a draft RFC, and a custom server is
documented as incompatible with `output: 'standalone'`, which this app uses. A
terminal needs a bidirectional socket, so it cannot live in the app process.

The app container is also the wrong place on its own terms. It runs read-only
with all capabilities dropped and is installed with `--ignore-scripts`, so it
has no writable workspace, no build toolchain and no native modules. Giving it
those things to host a shell would undo the isolation that makes it safe to
expose.

So the workbench is its own container with its own writable volume, reached by
the browser through Caddy at `/ws/*` and by the app over the private compose
network.

## Trust boundary

The workbench never decides whether something is allowed. It executes what the
app has already authorised:

- **Browser to workbench** carries a single-use ticket, HMAC-signed by the app
  with `HIKMAH_WORKBENCH_TOKEN`, valid for 30 seconds. The workbench verifies
  the signature and the `Origin`, and nothing else; it has no session store and
  no idea who is signed in.
- **App to workbench** carries the same shared token as a bearer credential over
  the private network, never exposed to the browser.

This is deliberately not a security boundary against the owner. It is a boundary
against the model and against anything that reaches the app without a session.

## Configuration

| Variable                 | Meaning                                                                    |
| ------------------------ | -------------------------------------------------------------------------- |
| `HIKMAH_WORKBENCH_TOKEN` | Shared secret, at least 32 characters. Generated by `deploy/configure.py`. |
| `HIKMAH_APP_ORIGIN`      | The exact HTTPS origin of the app, for the `Origin` check.                 |
| `HIKMAH_WORKBENCH_PORT`  | Listen port. Defaults to 3001.                                             |
| `HIKMAH_WORKSPACE_DIR`   | Writable working directory. Defaults to `/workspace`.                      |

It listens on all interfaces inside the container and must not be published to
the internet directly: Caddy is the only thing that should reach it.
